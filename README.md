## ✨ Features

### ✅ Currently Implemented
- ⚡ **Next.js 15** with App Router for blazing-fast performance
- 🎯 **TypeScript** strict mode for type safety
- 🎨 **TailwindCSS v4** with utility-first styling
- 🧩 **shadcn/ui** components with New York style
- 🖼️ **Lucide React** icons - lightweight and beautiful
- 📱 **Fully responsive** design (mobile, tablet, desktop)
- 🎭 **CSS Variables** theming system (easy customization)
- 🔧 **Path aliases** (`@/*`) for clean imports

### 🔜 Coming Soon
- 🗄️ **Prisma ORM** with PostgreSQL database
- 🔐 **Authentication** (NextAuth.js / Auth.js)
- 📝 **Job posting & management**
- 🔍 **Advanced search & filtering**
- 💾 **Save jobs** (bookmarking)
- 📧 **Email notifications**
- 👤 **User dashboard**
- 📊 **Admin panel**
- 🌙 **Dark mode toggle**

## 🚀 Quick Start

### Prerequisites
- Node.js 18.x or higher
- npm / yarn / pnpm
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/Abolfazlhgd/jobify-website.git
cd jobify-website

# Install dependencies
npm install

# Run development server
npm run dev
